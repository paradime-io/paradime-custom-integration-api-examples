# Quick Start Guide – Streamlit Integration

## 🚀 Get Started in 4 Steps

### Step 1: Download the Examples
Run this in the **Paradime IDE terminal** to get the repository:
```bash
curl -L https://github.com/paradime-io/paradime-custom-integration-api-examples/archive/refs/heads/main.zip \
     -o paradime-custom-integration-api-examples.zip
unzip paradime-custom-integration-api-examples.zip && \
     mv paradime-custom-integration-api-examples-main paradime-custom-integration-api-examples
cd paradime-custom-integration-api-examples
```

### Step 2: Install Dependencies
```bash
poetry install
```

### Step 3: Set Environment Variables
```bash
# GitHub access (for private repos)
export GITHUB_TOKEN="ghp_your_token_here"

# Paradime API credentials
export PARADIME_API_ENDPOINT="https://api.paradime.io"
export PARADIME_API_KEY="your_api_key"
export PARADIME_API_SECRET="your_api_secret"
```

### Step 4: Run the Full Pipeline
```bash
cd integrations/streamlit
python run_full_pipeline.py
```

That's it! Your Streamlit integration is now live in Paradime. 🎉

## 📋 What Gets Created

In Paradime, you'll see:

1. **App Node**: e.g. `F1 Analysis Dashboard`
   - Shows total SQL queries
   - Lists all dbt models referenced
   - Links to source code

2. **Chart Nodes**: One per visualization
   - e.g. `F1 Analysis Dashboard.Races Per Year`
   - Bar charts, line charts, dataframes, etc.
   - Each with lineage back to dbt models

3. **Lineage Graph**:
   ```
   dbt Model (int_f1__race_results_standings)
     ↓
   Streamlit App (F1 Analysis Dashboard)
     ↓
   Chart (Races Per Year)
   ```

## 🛠️ Configuration

All configuration is via environment variables — no code changes needed.

| Variable                | Default                                                          | Description                                                             |
|-------------------------|------------------------------------------------------------------|-------------------------------------------------------------------------|
| `STREAMLIT_REPO_URL`    | `https://github.com/paradime-sandbox/streamlit-f1-analysis`      | GitHub repo containing your Streamlit app(s)                           |
| `STREAMLIT_BRANCH`      | `main`                                                           | Branch to download                                                      |
| `STREAMLIT_APP_NAME`    | `F1 Analysis Dashboard`                                          | Display name for the App node(s) in Paradime                            |
| `STREAMLIT_FILE_FILTER` | *(built-in default path)*                                        | Comma-separated repo-relative `.py` paths to parse (one or more files) |

### Single file example

```bash
export STREAMLIT_REPO_URL="https://github.com/your-org/your-streamlit-app"
export STREAMLIT_APP_NAME="My Sales Dashboard"
export STREAMLIT_FILE_FILTER="dashboards/sales_app.py"
```

### Multiple files example

```bash
export STREAMLIT_REPO_URL="https://github.com/your-org/your-streamlit-app"
export STREAMLIT_APP_NAME="Analytics Suite"
export STREAMLIT_FILE_FILTER="apps/sales.py,apps/operations.py,apps/marketing.py"
```

All files are parsed in one run and merged into a single `target/streamlit_nodes.json`.  
Each App node is named `Analytics Suite – sales`, `Analytics Suite – operations`, etc.

### Use the built-in default

```bash
unset STREAMLIT_FILE_FILTER
```

## 🔍 Troubleshooting

| Problem | Fix |
|---------|-----|
| `GITHUB_TOKEN not set` | `export GITHUB_TOKEN="ghp_..."` |
| `Filtered file not found` | Check each path in `STREAMLIT_FILE_FILTER` is relative to the repo root |
| `None of the files were found` | All listed paths are missing — check for typos or wrong branch |
| `404 Not Found` | Verify the repo URL; ensure your token has `repo` scope |
| Paradime credentials missing | Set `PARADIME_API_ENDPOINT`, `PARADIME_API_KEY`, `PARADIME_API_SECRET` |
