# Quick Start Guide – Matillion Integration

## 🚀 Get Started in 3 Steps

### Step 1: Install Dependencies
```bash
cd paradime_custom_integration_api
poetry install
```

### Step 2: Set Environment Variables
```bash
# GitHub access (for private repos)
export GITHUB_TOKEN="ghp_your_token_here"

# Paradime API credentials
export PARADIME_API_ENDPOINT="https://api.paradime.io"
export PARADIME_API_KEY="your_api_key"
export PARADIME_API_SECRET="your_api_secret"
```

### Step 3: Run the Full Pipeline
```bash
cd integrations/matillion
python run_full_pipeline.py
```

That's it! Your Matillion integration is now live in Paradime. 🎉

## 📋 What Gets Created

In Paradime, you'll see:

1. **Pipeline Node**: e.g. `F1 Custom Connector Load`
   - Describes the entire orchestration pipeline
   - Links to the `.orch.yaml` source file on GitHub

2. **Job Nodes**: One per non-Start component
   - e.g. `F1 Custom Connector Load.Load Drivers`
   - Shows which API endpoint is called
   - Shows which Snowflake table is written

3. **Lineage Graph**:
   ```
   Matillion Pipeline (F1 Custom Connector Load)
     ↓
   Matillion Job (Load Drivers)
     ↓
   Snowflake Table (f1_drivers_cc)
     ↓
   dbt Source → dbt Models
   ```

## 🛠️ Configuration

All configuration is via environment variables — no code changes needed.

| Variable                    | Default                                                   | Description                                     |
|-----------------------------|-----------------------------------------------------------|-------------------------------------------------|
| `MATILLION_REPO_URL`        | `https://github.com/paradime-sandbox/matillion-pipelines` | GitHub repo containing your `.orch.yaml` files  |
| `MATILLION_BRANCH`          | `main`                                                    | Branch to download                              |
| `MATILLION_PIPELINE_FILTER` | *(empty — all pipelines)*                                 | Comma-separated list of specific files to parse |

### Examples

```bash
# Point at your own repo
export MATILLION_REPO_URL="https://github.com/your-org/your-matillion-repo"

# Process only one pipeline
export MATILLION_PIPELINE_FILTER="my_pipeline.orch.yaml"

# Process two specific pipelines
export MATILLION_PIPELINE_FILTER="pipeline_a.orch.yaml,pipeline_b.orch.yaml"

# Process all pipelines (default)
unset MATILLION_PIPELINE_FILTER
```

## 🔍 Troubleshooting

| Problem | Fix |
|---------|-----|
| `GITHUB_TOKEN not set` | `export GITHUB_TOKEN="ghp_..."` |
| `No .orch.yaml files found` | Check `MATILLION_REPO_URL` and `MATILLION_BRANCH` |
| `None of the filtered files found` | Paths in `MATILLION_PIPELINE_FILTER` must be relative to the repo root |
| `404 Not Found` | Verify the repo URL; ensure your token has `repo` scope |
| Paradime credentials missing | Set `PARADIME_API_ENDPOINT`, `PARADIME_API_KEY`, `PARADIME_API_SECRET` |
